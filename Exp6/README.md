# Exp6: PHP Database and Page (DB + index)

## AIM
Create a PHP page that connects to a database and renders content.

## OBJECTIVES
- Use PHP files (`db.php`, `index.php`) for server-side logic.
- Demonstrate CRUD or data display from a database.
- Run on a local PHP server.

## PROBLEM STATEMENT
Implement a server-side page that fetches data via `db.php` and renders it in `index.php`. Ensure database connection and query flow works properly.

## Theory
PHP is a server-side scripting language that generates HTML dynamically. It can connect to databases, process forms, and produce rendered HTML for clients. Proper configuration (PHP runtime, database credentials) is needed.

## Run
1. Start PHP server in folder: `php -S localhost:8000`
2. Open `http://localhost:8000/index.php`.
