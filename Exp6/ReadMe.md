Problem Statement: Create a PHP-MySQL system to record and display simple workshop attendance sign-ups (name, email, session) with add and list functions.

Theory:
1. PHP scripts handle form input, validation, and SQL queries in procedural style.
2. MySQL stores attendee records in a table with fields id, name, email, session, timestamp.
3. Use mysqli extension for connection, insertion, and retrieval using prepared queries.
4. Simple page flow: form submit -> insert -> confirmation -> list existing sign-ups.
