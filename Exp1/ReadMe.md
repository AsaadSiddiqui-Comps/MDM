# Exp1: Git Setup and Workflow

## AIM
Install Git and set up a new repository.

## OBJECTIVES
- Learn fundamental Git commands: `git add`, `git commit`, `git status`, `git log`.
- Modify files and track changes with `git diff`.
- Create and manage branches for version control with `git branch`, `git checkout`, `git merge`.

## PROBLEM STATEMENT
Use Git & GitHub for version control:
- Initialize a repository (`git init`).
- Track files (`git add`) and save snapshots (`git commit`).
- Push commits to GitHub (`git remote add origin`, `git push`).
- Create and manage branches and open a Pull Request.

## STATUS
Completed: repository initialized, files committed, branch workflow used, and changes pushed with PR process followed.
