# Exp8: XML + XSL Report

## AIM
Build a styled report using XML data and XSL transformation.

## OBJECTIVES
- Understand XML structure for data storage.
- Use XSL to transform XML into readable HTML.
- Display output in the browser.

## PROBLEM STATEMENT
Create an XML report (`report.xml`) and use XSL (`reportcard.xsl`) to transform it into formatted HTML. Confirm the transformation works with browser or processor.

## Theory
XML stores structured data in nested tags while XSL instructions define presentation rules. XSLT (XSL Transformations) converts XML documents into HTML or other XML formats, separating data and display.

## Run
Open `report.xml` in a browser that supports XSLT, or use command-line tooling to transform and inspect HTML.
