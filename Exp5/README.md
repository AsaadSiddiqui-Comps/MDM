# Exp5: AJAX Interaction Demo

## AIM
Create an interactive web page that uses AJAX to fetch and display data without full page reload.

## OBJECTIVES
- Use JavaScript `fetch`/`XMLHttpRequest` to request data from a server endpoint.
- Update UI elements dynamically when data arrives.
- Handle loading state and error cases flow.

## PROBLEM STATEMENT
Implement a simple AJAX-powered interface: clicking a button should load data asynchronously and render results in the page. This exercise reinforces client-side scripting and asynchronous operations.

## Theory
AJAX (Asynchronous JavaScript and XML) allows web applications to request data from servers without refreshing the page. Modern implementations via `fetch` return promises and update DOM on success. This improves UX by enabling seamless data interactions.

## Run
Open `index.html` in a browser or run a local server (`npx serve` or similar). If the example uses an API endpoint, ensure a matching backend or mock response is available.
